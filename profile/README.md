## Open source com propósito

Produtos comerciais, propriedade intelectual e código de clientes permanecem **privados por design**. Em público, contribuímos com ferramentas, padrões, exemplos e documentação que possam acelerar o trabalho de outros desenvolvedores.

Iniciativas do nosso ecossistema:

- [WP24H Plugin Boilerplate](https://github.com/WP24Horas/wp24h-plugin-boilerplate) — base modular e configurável para plugins WordPress profissionais.
- [WP Plugin Readme Validator](https://github.com/asllanmaciel/wp-plugin-readme-validator) — CLI e GitHub Action para validar metadados antes da publicação.
- [GitHub Webhook Security Guide](https://github.com/asllanmaciel/github-webhook-security-guide) — exemplos práticos de validação HMAC em PHP e Node.js.
